# SecurePay Financial - Company Profile

## Company Overview

SecurePay Financial is a fictional fintech company that provides online payment and digital financial services to customers.

## Company Size

- 150 employees
- Remote and office-based workforce
- Technology team
- Security team
- Finance team
- Customer support team
- Compliance team

## Technology Environment

SecurePay Financial uses:

- Amazon Web Services (AWS)
- Microsoft 365
- Employee laptops
- GitHub
- Customer web application
- Customer database
- Third-party software vendors

## Sensitive Information

The company handles:

- Customer Personally Identifiable Information (PII)
- Financial information
- Employee information
- Account credentials
- Business confidential information

## Business-Critical Systems

The most important systems include:

- Customer payment application
- Customer database
- AWS cloud environment
- Microsoft 365
- Employee endpoints
- Third-party payment services

## GRC Objective

The goal of this project is to identify cybersecurity risks, evaluate existing security controls, identify control gaps, and recommend improvements using the NIST Cybersecurity Framework 2.0.
